## 修改建议 / Suggestion

用户明确指的是：进入房间、点击一个方向、打开方向工作台后，工作台的每个内容板块可以改、可以增加。只开放本月行动试填并不能满足这个需求。Example 首先要让访客试填工作台的目标、反面校准、输入、实践、输出、前进证据和回看等内容；本月行动的添加和编辑是辅助演示路径。本次仍是教学试用，不是保存个人地图或确认真人经历。

## 解决思路 / Approach

保持公开案例 JSON 为不可变的虚构样本；Example 的每个现有方向可在当前页面里临时修改或补入其工作台内容，试填只改变该页面内存中的视图副本，不改变原始样本。刷新、重新打开或重置均恢复原样。工作台字段对应方向的 `desired_state`、`anti_vision` 和 `operating_loop.input/practice/output/evidence/review`；“稳定行动”等汇总文案应从试填字段重新呈现，而非另造一份权威。`operating_loop.evidence` 是对“什么算前进证据”的描述，不得把它冒充已经发生的行动记录。月度行动试填可保留作为辅助路径。

Example 不读取或写入私人 API、私人文件、Blank/Personal 的 localStorage 或其他持久化介质。导出仍给出原始虚构案例，不夹带访客试填；页面需清楚告知试填不会保存，也不能借此改写其他模式的数据。

## 技术方案 / Plan

- 在 `monthly/index.html` 与 `monthly/app.js` 为方向工作台各内容板块提供可发现的试填入口：已有文字可编辑，空白字段可补入；保留方向 id、房间归属和源案例不变。工作台切换方向后，试填内容仍在当前页面可见。
- 更新 Example 内存视图中的方向字段，并经现有模型契约校验；同一字段在房间、九宫格和工作台出现时应同步呈现。不要开放 Personal 的网页编辑，也不要把 Example 写入 Blank 暂存或任何持久化存储。
- 保留本月行动的临时添加与编辑，但在交互和测试优先级上从属方向工作台。前进证据描述与真实行动记录在界面上保持区分。
- 刷新和重置从 `examples/teaching-life-grid-monthly.json` 恢复原样；Example 导出始终使用原始案例，而不是试填后的内存副本。更新 `AGENTS.md`、`README.md` 的模式边界与录制说明。
