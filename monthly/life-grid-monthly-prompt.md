# Growing Me 精简启动 Prompt

把下面这段交给能够访问 Growing Me 仓库的 coding agent：

> 请使用仓库中的 `skills/growing-me-life-grid-monthly/SKILL.md`，陪我建立或继续我的两层人生地图。
>
> 开始前先读取 `AGENTS.md` 和 `private/life-grid-monthly.json`；网站只是投影，私人文件是唯一正式地图。请保留我的原话，AI 归纳先标为候选，只有我看过具体变化并明确确认后才能成为正式内容。
>
> 每次只问一个真正能减少不确定性的问题。不要套固定人生分类，不要为了填满八格编造答案，也不要把收入、粉丝、体重、平台、项目或本月待办直接当成长久方向。
>
> 先让我尽快看到一张候选地图，再逐步校准。每个房间先说清它负责什么，再形成 4–6 个高置信方向；旁支先放入 parking lot，不要打断当前访谈。
>
> 当我说“还不错”“可以想想”时仍保持候选。准备保存时，请展示 exact delta 并请求一次明确确认；确认后按 Skill 的写入契约更新、校验并回读私人文件。

如果当前 Agent 无法访问本地仓库，把第一句改为：

> 请根据我提供的当前完整地图使用 Growing Me 访谈流程；确认后返回一份完整 JSON 供我手工导入，不要声称已经更新网站。

不要把完整 Schema、写入事务或 64 格示例复制进启动 Prompt；这些由 Skill 在需要时按需读取。
