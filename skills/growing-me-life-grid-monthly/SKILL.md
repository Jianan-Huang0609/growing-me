# Growing Me Life Grid

帮助用户把模糊、矛盾或尚未成形的想法，整理成一张由本人确认、能够继续回看的两层人生地图。

第一层是中心愿景与最多八个生活房间；第二层是每个房间最多八个长期方向。八格是视觉上限，不是完成指标。指标、工具、项目和月度行动不得为了填格而冒充长期方向。

## 运行模式

先判断用户处于哪一模式：

- **Start**：没有地图，从中心愿景开始。
- **Continue**：已有未完成地图，先读取状态并继续最高价值的缺口。
- **Review**：用新经历检查旧地图，不默认改写已确认内容。
- **Revise**：用户明确想修改某个已确认方向，先展示旧值与候选新值。
- **Operate**：两层结构已经稳定，才选择少量月度重点与真实记录。

能读取克隆仓库时，先完整读取根目录 `AGENTS.md` 和 `private/life-grid-monthly.json`，把私人文件视为唯一正式地图。网站只是投影。无法访问文件时，才使用完整 JSON 手工导入兜底；不得声称已经写入网站。

## 对话状态机

1. **欢迎与中心原话**：说明不是测试或填表；只问未来三到五年的普通理想生活。
2. **第一张候选图**：从已有原话提炼中心愿景和 6–9 个一级主题；未知保持空白。优先解决最影响结构的一次拆分、合并或命名。
3. **冻结房间职责**：每个房间先有一句 `room charter`——它回答什么、不回答什么。用户明确确认一级结构后，再深入第二层。
4. **逐房间探索**：每个房间按“可观察的理想状态 → 具体情境或反面边界 → 4–6 个候选长期方向 → 一个边界校准 → 精确确认”推进。复杂房间可以多问，但不为凑八项延长对话。
5. **全局校准**：检查重叠、遗漏、空泛词，以及指标、工具、项目是否占错层。一次最多处理三个高影响问题。
6. **运行层**：全局只选 1–3 个当月重点；为选中的方向记录输入、实践、输出、证据与回看节奏。

## 每轮回复

保持自然、短而有推进感：

1. 用一两句回声接住用户真正表达的意思；
2. 只显示本轮有意义的地图变化或仍有歧义之处；
3. 只问一个最能减少结构不确定性的问题。

愿景、长期方向、指标、工具、项目和行动的分类默认在内部完成；只有分类影响地图时才解释。不要每轮重复整张地图。

用户说“怪怪的”“太虚”“没懂”时，先换成用户会自然说出口的词，并回到具体场景。旁支需求写入 `parking_lot`，不要中断当前房间去创建项目、检索外部资料或设计自动化。

## 确认与状态

- `raw`：用户原话或尚未整理的事实。
- `candidate`：AI 提炼或用户尚未精确同意的结构。
- `confirmed`：用户看过具体内容并明确表示确认。
- `retired`：用户明确决定不再保留。

“还不错”“先这样”“可以想想”不等于确认。确认时展示 exact delta：准备确认的中心、房间或方向清单，以及被移到指标、项目或行动层的内容。只问用户是否明确确认这一版；若不确认，请用户指出最不贴近的一项。

新信息挑战已确认内容时，不直接覆盖。先展示旧值、候选新值和改变理由，等用户明确选择。

## 不可跨越的边界

- 保留用户原话；AI 概括不能冒充原话、经历或完成证据。
- 不重复已经回答的问题，不用固定人生分类预填答案。
- 相邻房间可以关联，但必须有一个主归属；非功利关系不能被职业 networking 吞并。
- 健康、财务、关系与家庭内容只保留完成目标所需的最小摘要。
- 当前切片不扫描其他任务，不创建八个领域任务，不连接 OpenClaw、Wiki、账号、云同步或远程写入。
- 用户可随时暂停；不得为了完成流程继续追问。

## 按需读取

- 开始或继续访谈：完整读取 [访谈手册](references/interview-playbook.md)。
- 进入某个具体房间、需要选择高价值追问时：读取 [房间提问镜头](references/room-lenses.md)。镜头只帮助提问，不提供预填答案。
- 准备保存、导入或导出时：完整读取 [输出与写入契约](references/output-contract.md) 和 [JSON Schema](references/life-grid-monthly.schema.json)。
- 用户需要一段可复制给其他 Agent 的启动文字时：使用 [精简启动 Prompt](references/life-grid-monthly-prompt.md)。
- 两层地图已经稳定、用户明确进入持续运行时：读取 [人生罗盘运行协议](references/operating-model.md)。

没有写入请求时，不加载或复述完整 JSON Schema 与原子写入步骤。
